# جاهای خالی که شما تکمیل می‌کنید

همهٔ بخش‌هایی که به مجوز، قرارداد یا هویت حقوقی شما نیاز دارند عمداً خالی مانده‌اند. در کد با `TODO(operator)` علامت خورده‌اند.

## ۱. نمادها، مجوزها و مشخصات حقوقی → `config/trust.json`

| بخش | از کجا | چه چیزی بگذارید |
|---|---|---|
| `badges[enamad]` | enamad.ir | آدرس تصویر نماد (`image`) و لینک استعلام (`link`) که enamad به شما می‌دهد. **کد HTML نماد را نگذارید**؛ فقط این دو آدرس. |
| `badges[samandehi]` | samandehi.ir | مثل بالا |
| `badges[charity]` | مؤسسهٔ خیریهٔ همکار | تصویر مجوز یا لینک استعلام |
| `organization` | اساسنامه/آگهی ثبت | نام، شمارهٔ ثبت، نشانی، تلفن، ایمیل |
| `partnerCharity` | مجوز مؤسسه | نام، شمارهٔ مجوز، مرجع صدور |
| `documents` | قراردادها | عنوان، شماره، صادرکننده و لینک فایل (مثلاً PDF در `public/docs/`) |
| `sourceCodeUrl` | گیت‌هاب | آدرس همین مخزن |

تا زمانی که `DEMO_MODE=true` است، جای خالی‌ها با برچسب «جایگاه نماد» نمایش داده می‌شوند. در حالت واقعی، موارد خالی به‌طور خودکار پنهان می‌شوند تا هیچ نماد ناقصی دیده نشود. دامنهٔ تصویر نمادها به‌طور خودکار به CSP اضافه می‌شود.

## ۲. پیامک (کد ورود) → `.env`

```
SMS_PROVIDER=kavenegar
SMS_API_KEY=کلید پنل
SMS_TEMPLATE=نام قالب verify lookup (با متغیر %token)
```

آداپتور کاوه‌نگار آماده است. برای سرویس دیگر (SMS.ir، قاصدک و…) یک مورد به `server/src/providers/sms.js` اضافه کنید.

## ۳. درگاه پرداخت → `.env`

پیش‌نیاز: نماد اعتماد و ثبت کسب‌وکار. آداپتور زرین‌پال (REST v4) آماده است:

```
PAYMENT_PROVIDER=zarinpal
ZARINPAL_MERCHANT_ID=مرچنت کد
ZARINPAL_SANDBOX=false
```

برای درگاه‌های دیگر (پی‌پینگ، آی‌دی‌پی، سداد و…) یک آداپتور با دو تابع `start` و `verify` در `server/src/providers/payment.js` اضافه کنید.

## ۴. استعلام و پرداخت قبض → `server/src/providers/billpay.js`

در حالت `mock` فقط ارقام کنترلی بررسی می‌شود و پرداخت شبیه‌سازی می‌شود. برای حالت واقعی، با یکی از سرویس‌دهنده‌های API بانکی (مثل فینوتک یا جیبیت) یا بانک همکار قرارداد ببندید و دو تابع `inquire` و `pay` را پیاده کنید.

**مدل مالی پیشنهادی:** پول خیّرین به حساب مؤسسهٔ خیریهٔ همکار واریز می‌شود و همان لحظه از طریق API پرداخت قبض، به سازمان صادرکننده پرداخت می‌شود. برای قسط وام، اجاره و درمان، کارشناس پس از تکمیل مبلغ، واریز را به حساب طلبکار انجام می‌دهد و شمارهٔ پیگیری را در پنل ثبت می‌کند.

## ۵. راه‌اندازی واقعی

```
NODE_ENV=production
PUBLIC_URL=https://دامنه-شما.ir
DATA_KEY=(با دستور داخل .env.example بسازید و جای امن نگه دارید)
DEMO_MODE=false
TRUST_PROXY=true
ADMIN_PHONES=شماره کارشناسان
```

اگر هر کدام از این تنظیمات ناامن باشد، برنامه اجرا نمی‌شود و دلیلش را می‌گوید.
