## انتشار در کافه بازار و مایکت

برنامه یک وب‌اپ قابل نصب (PWA) است. برای فروشگاه‌های اندرویدی آن را در یک پوستهٔ اندرویدی قرار دهید. دو راه:

**راه ۱ — Capacitor (پیشنهادی):**

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init Mehrpol ir.yourdomain.mehrpol --web-dir public
# در capacitor.config.json:  "server": { "url": "https://دامنه-شما.ir" }
npx cap add android
npx cap open android   # در Android Studio: Build → Generate Signed Bundle/APK
```

**راه ۲ — Trusted Web Activity** با ابزار Bubblewrap.

سپس:

- [ ] حساب توسعه‌دهنده در کافه بازار و مایکت (با هویت خودتان)
- [ ] آیکون ۵۱۲×۵۱۲، تصاویر صفحه، توضیحات فارسی
- [ ] لینک سیاست حریم خصوصی
- [ ] بررسی قوانین هر فروشگاه دربارهٔ پرداخت داخل برنامه برای کمک‌های خیریه
